This file is to record all the event ID numbers used beyond the vanilla GC to prevent ID conflict.
Vanilla GC uses IDs upto <100'000>

Aluns Reformation Mod - <717'000'000-718'000'000> [not all numbers are used but it creates a suitable buffer]
Altered SWE event file - (no new ID tags used) required for Swedish Regents before Gustav Vasa.
Altered ENG event file - to take out occitan culture at end of 100yr war
Altered FRA event file - to trigger Burgundian response to Chambers of Reunion event, took out joan event.
Altered HAB/HUN event files - needed for culture changes, Austria gains cultures through events, not at start.
Altered FLAVOUR_ENG event file - allows scotland to have scots-british flavour events if GBR not founded.
Altered BYZ event file - to have the council of florence only trigger if the Ottomans still exist.
deleted FLAVOUR_TOS and FLAVOUR_MLO event files
Altered BUR event file - for BUR to give Paris to FRA if they hold it at death of Charles III.
