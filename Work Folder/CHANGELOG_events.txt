2. ARCHITECTURE & UPDATE-RESILIENCE SYSTEM
================================================================================
[2026-10-08] Core Architecture Design:
1. Scenario Isolation:
   - Dedicated scenario file: "Scenarios/1337 - Alternate Destinies.eeg".
   - Loads base scenario data while referencing the master modular event loader.
2. Master Loader:
   - File: "Db/events_alt_master.txt".
   - Modularly references "Db/Decisions/alt_*.txt" and "Db/Events/alt_*.txt".
   - Completely decouples custom logic from upstream vanilla files (Byzantine.txt,
     OAJF_italy.txt, mameluks.txt, etc.).
3. Startup Sleeper Events:
   - Event 3009000 dynamically disables conflicting vanilla linear progression 
     events at scenario start without altering author's base event files.
4. One-Click Patch Applier:
   - File: "Work Folder/Alt_Patches/Apply-AltPatches.ps1".
   - Associated patch files: countries_patch.txt, cultures_patch.txt, 
     religions_patch.txt, monarchs_egy_patch.txt.
   - When upstream mod updates overwrite core database tables, executing this 
     script instantly restores all custom tags, cultures, religions, and dynasties.
